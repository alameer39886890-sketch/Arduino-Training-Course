Welcome to the official repository for the Arduino Training Course! This repository contains comprehensive course materials, practical codes (`.ino`), circuit diagrams, and project examples used during the training sessions.

## 📌 Course Overview
This course is designed to take students and beginners from absolute basics to building interactive embedded systems and real-world projects using the **Arduino Uno** board. The curriculum bridges theoretical electronics with hands-on programming and practical implementation.

---

## 📂 Course Contents & Topics

### 1. Introduction to Microcontrollers & Arduino
- Overview of open-source electronics platforms[cite: 46].
- Introduction to Arduino board families (Uno, Nano, Mega, ESP32/ESP8266)[cite: 47].
- Deep dive into **Arduino Uno** specifications (ATmega328P microcontroller, digital/analog pins, power pins, and PWM)[cite: 51, 52].

### 2. Software & Programming Fundamentals
- Setting up the **Arduino IDE**[cite: 6].
- Structure of an Arduino sketch (`setup()` and `loop()` functions)[cite: 12].
- Syntax, comments, data types (int, float, char, long, byte), and operators[cite: 13, 25, 37].
- Control statements (`if`, `else`, `for` loops)[cite: 32, 35].

### 3. Core Practical Experiments & Projects
- **Digital I/O & LEDs:** Controlling built-in and external LEDs, Traffic Light simulation[cite: 15, 19].
- **Serial Communication:** Sending and receiving data via the Serial Monitor[cite: 27, 31].
- **PWM (Pulse Width Modulation):** Controlling LED brightness and motor speeds[cite: 63].
- **Sensors & Modules Interfacing:**
  - **LM35:** Temperature sensor reading and processing[cite: 66].
  - **MQ-2 / MQ-5:** Gas and smoke detection sensors[cite: 69].
  - **HC-SR04:** Ultrasonic distance measurement sensor[cite: 74].
  - **IR Sensor:** Infrared obstacle detection and reflection[cite: 80].
- **Actuators:**
  - **Servo Motor:** Precise angle and position control using the Servo library[cite: 89].
- **Displays:**
  - **16x2 LCD & I2C Interface:** Displaying text, sensor readings, and counters[cite: 83, 86, 93].

---

## 🛠️ Requirements & Setup
To run the codes and simulate circuits from this repository:
1. Install the **Arduino IDE**[cite: 6].
2. Have an **Arduino Uno** board or use online simulation tools (like Tinkercad)[cite: 49, 72].
3. Install required libraries (e.g., `Servo.h`, `LiquidCrystal`, `LiquidCrystal_I2C`) via the Arduino Library Manager[cite: 67, 86, 91].
